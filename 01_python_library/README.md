# 📚 Projet 1 : Premiers pas avec Python

## 📝 Description du projet
Ce projet consiste à créer une application en ligne de commande pour gérer une bibliothèque personnelle. Il s'agit de la première étape de mon parcours, conçue pour maîtriser les bases fondamentales de la programmation en Python avant de basculer sur des architectures de données complexes.

## ⚙️ Fonctionnalités & Étapes réalisées
1. **Système de gestion complet (CRUD) :** Permet d'ajouter, de modifier et de supprimer des livres de la bibliothèque personnelle.
2. **Outils de recherche et d'affichage :**
   * Affichage de tous les livres disponibles dans le catalogue.
   * Recherche rapide d'un livre par son titre ou son auteur.
   * Tri dynamique des livres par date d'ajout ou par catégorie.
3. **Architecture Orientée Objet :** Structuration complète du projet avec des classes distinctes pour représenter les entités de manière isolée (les livres et la bibliothèque).
4. **Persistance des données :** Sauvegarde et chargement automatique des données localement dans un fichier au format **JSON**.

## 🎯 Objectifs atteints
* Comprendre et appliquer les bases de la programmation orientée objet (POO).
* Savoir structurer un projet propre à l'aide de modules et de classes.
* Manipuler des bibliothèques intégrées comme `json` pour la gestion et la persistance de fichiers.

## 🛠️ Technologies utilisées
* **Langage :** Python 3
* **Persistance :** Format JSON (via les modules natifs intégrés)

## 🚀 Comment lancer et tester l'application
1. Ouvrez votre terminal Windows ou VS Code dans ce dossier :
   ```cmd
   cd 01_python_library
   ```
2. Exécutez le script principal pour lancer l'application :
   ```cmd
   python library.py
   ```
